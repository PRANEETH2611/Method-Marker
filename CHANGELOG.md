# Changelog

## 1.1.0

- Added multi-language markers for JavaScript, TypeScript, React variants, C, C++, C#, Go, Rust, Kotlin, PHP, Python, Ruby, and Shell Script.
- Added language-specific `//` and `#` marker syntax.
- Preserved Java methods, constructors, overloads, nested symbols, indentation, and duplicate prevention.
